# Typography

The active typefaces match the MirroS research pages:

- DM Sans: body text and controls.
- Newsreader: project title and section headings.
- Poppins 500: navigation.

The WOFF2 files were copied from `MirroS-Lab.github.io/code-as-world/fonts`.
Each family is distributed under the SIL Open Font License; the corresponding
`*-LICENSE.txt` files are included here, sourced from the Google Fonts repository.
The original Instrument Sans font and its license remain available for older versions.
